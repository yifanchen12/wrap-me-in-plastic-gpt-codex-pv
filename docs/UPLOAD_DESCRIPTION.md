# 投稿简介

如果 GPT 是她，Codex 就是承载她的代码世界。

本视频是对 UP 主「西西弗斯的风车」《〖4K〗如果聊天窗口就是她的整个世界 —— world.execute(me)》的个人非商业二创，基于 MisakaZentai 的开源 PV 项目改编。沿用原作的代码动画与镜头框架，融合白龙娘角色参考，改为 GPT / 6-Astra 与 Codex 的灰白代码世界，并使用《Wrap Me In Plastic》作为本版配乐。
